Historique de cette page
Une première version de cet écran reproduisait le menu XMB de la PlayStation 3, à partir d'un projet fan-made en code source ouvert (menonparik/xmb-on-web). Elle a été remplacée par la version actuelle, inspirée du menu de la Wii — voir pourquoi ci-dessous.
Pourquoi aucun fichier Wii réel n'est utilisé
Une extraction du menu système Wii (archives .arc, textures .tpl, banque sonore .brsar, polices .brfna, données Mii, textes officiels) a été fournie comme point de départ. Contrairement au projet XMB ci-dessus, ce ne sont pas des fichiers libres : c'est le firmware propriétaire de Nintendo, dumpé depuis une vraie console. Les réutiliser (icônes, sons, polices, textes) reviendrait à redistribuer du contenu protégé par le droit d'auteur de Nintendo sur un site public.

Seuls la disposition et le principe d'interaction du menu Wii ont donc été repris — en code, icônes, couleurs et son 100% originaux, comme détaillé dans le tableau ci-dessous.

Notre écran d'accueil (connexion requise)

Se connecter avec un compte admin pour voir la grille ; flèches directionnelles ou souris/tactile pour naviguer.
